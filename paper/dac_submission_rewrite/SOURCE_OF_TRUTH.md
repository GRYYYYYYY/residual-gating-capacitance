# Source of truth and rebuilding

`main.tex` is the authoritative manuscript. `references.bib` is the authoritative bibliography. `tables/*.tex` and all figures are generated from existing recorded data by `build_figures.py`; do not edit their numbers manually. `DAC_REWRITE.md` is generated by `sync_markdown.py` from the same TeX, its included tables, captions and compiled bibliography. It is a reading copy, not an independently edited paper.

Compile the supplied artifacts without accessing any experimental assets:

```sh
cd paper/dac_submission_rewrite
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
python3 sync_markdown.py
```

Regenerate figures/tables from existing source records, from repository root in this workspace:

```sh
source experiments/dac_characterization_20261114/env.sh
"$DAC_PYTHON" paper/dac_submission_rewrite/build_figures.py
```

The derivation script reads records and draws figures only. It does not load model weights, import model runners or execute training, inference, timing, FEM, PEX, or STA. Large assets are referenced by paths and hashes, not copied into this manuscript. Rebuilding figures elsewhere requires those source records; compiling supplied TeX/PDF figures does not. IEEE class/style are bundled with their original license notices. Generated PDF page raster previews and transient LaTeX logs are local checks, not scientific data.
