## 解释边界与研究决策

本次检验的是嵌套低支持协议：S_L⊆S_H，但数量和几何覆盖一起改变。H恢复原sampler分布，并按冻结seed重新开始其episode流；它不是恢复历史optimizer/RNG轨迹后的第12001步。已知153节点训练支持46/77/107/138或整宽136，与B4/8/16/32存在设置失配；匹配更新的D将该协议效应与单纯额外训练的C区分，但不证明纯数量因果机制。

至少一个架构的D未在三个seed稳定为正；只按连续效应与区间陈述，不扩大为稳定机制。 Full-L的G在三个seed均为正，给出当前FEM设置内的局部架构线索；仍须结合尾部、原支持退化和计算成本。

旧MLP/CNP等在相同固定S/Q上的新主指标描述性重算见 HISTORICAL_DESCRIPTIVE.csv；它们没有获得本次匹配续训机会，不能据此声称公平训练优越。原始旧E1三成员均值与当前逐成员均值也有非线性聚合差异。没有重训任何这些基线。

保持限定规则补全主张；不升级普遍复杂门控必要性、全工艺表征效率、真实场求解加速、跨工艺总体或签核准确性。0.2882/0.2908阈值与B4首次已测下限结论不变；没有B1–3、没有新工程容差。原迁移、native PEX/STA及特定条件下Full相对binary的约+7.64 ps P99 slack误差差异没有重测，不据本机制实验宣称修复。本轮完成即停止，不追加搜索、模型、工艺或下游实验。可以保留局部机制结果；若未来另行研究，仍缺独立工艺/部署证据和工程收益阈值，本轮不自动获取。
