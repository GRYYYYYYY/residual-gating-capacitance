## 1. 论文立意必须调整到真实 EDA 流程

### 1.1 核心表述

将“补齐一个缺条目的查找表”改成：

**Characterization-conditioned capacitance estimation at uncharacterized geometries in rule-based parasitic extraction.**

建议标题：

**Characterization-Conditioned Capacitance Estimation for Rule-Based Parasitic Extraction**

这里的 characterized samples 是给定工艺、模式族和工艺角下已有的参考样本；query 是实际提取中需要估值的几何。规则库本来就是离散的，不假设其损坏、漏传或缺失了一套本应完整交付的条目。

“使用已有电容值”不是独立创新声明，因为插值也使用这些值。贡献应写为：**在相同表征数据条件下，结合跨表学习、数值锚点与条件化残差，改进非采样几何的估计，并保留现有规则提取接口。**

不要把“晶圆厂直接提供 LUT”写成所有流程的唯一事实。统一用 process-specific pre-characterized rules；需要描述来源时，说明规则可由工艺文件、参考提取工具和校准流程产生。传统模式方法还包括经验公式，不能把所有商业工具概括成简单多线性插值。

### 1.2 定义：非节点不等于外推

对一个固定 process/corner/pattern/context，记可用表征集合为：

`S = {(x_i, c_i)}; Q = {x_q}`，其中 `c_q` 仅供独立评估。

明确区分：

| 查询类别 | 定义 | 在文章中的作用 |
|---|---|---|
| On-grid | 查询与该规则的真实表征节点一致 | 接口与参考一致性控制 |
| Off-grid / in-support | 查询不是节点，但位于可用样本的有效支持区域内 | 本轮主要研究对象：插值估计 |
| Off-grid / out-of-support | 查询超出可用样本支持区域，且仍满足明确的几何使用条件 | 单列的边界预测结果 |
| Unsupported | 模式、材料、导体拓扑或输出语义无法由当前接口表示 | 计入覆盖率与排除原因，不冒充外推 |

高维支持以独立几何方向及其有效支持区域判定；不能仅用各坐标 min/max 包围盒。秩退化、落在支持仿射空间之外的查询单独标记。

### 1.3 30% 等实验的新解释

保留已完成的随机、块状、边界留出实验及原始数值，把它们放入“Controlled characterization subsampling”。30% 表示从一个有参考值的集合中留出 30% 作为评估查询，剩余点模拟有限表征支持；不表示实际 PDK 有 30% 丢失，也不是现场查询分布的测量。

固定预算实验写为 characterization-support-size sensitivity。已有最小达标预算是回顾性评估，不是部署时可读取查询真值的停止准则。

不要把这些受控实验改名为本轮的新 off-grid 实验。新实验要求 Q 的物理坐标不属于所比较原始表征节点集合。

### 1.4 三种部署与证据分别命名

1. **Query-level evaluation/replay**：对从实际提取中记录的查询离线调用模型，检验该查询的电容精度。它不等于已经在线替换提取器。
2. **Offline rule enrichment**：预测附加规则点，生成工具可消费的增强规则文件，随后使用原生提取器。已有规则导出是这一方向的基础。
3. **In-extractor replacement**：在原生求值调用点真正接入模型，并完成提取/STA 和成本验证。只有实际实现才使用这一表述。

优先把第 1 项做扎实；第 2 项在格式兼容时扩展；第 3 项不作为本轮必须完成的重型工程。

### 3.2 工艺材料匹配是前置条件

为每个可用 process/corner 建立表格：layout、LEF、规则文件、材料栈、金属厚度、高度、介电常数、偏置/有效宽度定义、求解器及来源哈希。

**不能只因两个文件都叫 ASAP7，就认定公开规则与 CTF-derived FEM 是同一物理系统。** 检查层号映射、厚度、介质、上下边界、工艺角、几何偏置及 ground 定义。缺少厚度或介电资料时不能只从普通 tech LEF 推断完整静电材料栈。

优先选择既有布局和物理资料最完整的工艺。目标是至少两个可物理对齐的工艺、每工艺至少两个布局；这不是允许捏造材料或补齐样本数量的硬配额。若只有一个工艺能够对齐，完成该工艺的结果并据实报告。

### 3.3 必须区分真实截面与模板投影

当前 `pdkcap/reference.py::geometry` 的截面包含对称同宽侧线、固定上下文电极和明确边界。它不是任意实际布线截面的通用解析器。

每条查询必须标注以下等级：

- **EXACT_LAYOUT_SECTION**：保留实际切片的导体形状、间距、宽度、连接及材料，当前比较接口可表达所需分量。
- **NATIVE_PATTERN_INSTANCE**：来自原生提取器明确采用的规则模式实例；其参数/上下文对应真实查询，但物理参考解的是原生简化模式。可用于隔离规则求值误差。
- **LAYOUT_PARAMETERIZED_TEMPLATE**：仅从布局取尺寸，再套用理想化模板。这是布局参数驱动的模板实验，不能称完整真实截面验证。
- **UNSUPPORTED**：不可表达或不可校准，给出原因。

优先完成前两级。不得将不对称实际侧线偷偷镜像成对称侧线；不得用平均间距、相同宽度或 ground 平板替换真实几何却不记录映射。若只能完成第三级，保留其结果但论文标题、图注和结论应准确命名，不声称完成用户指定的最高级验证。

### 3.4 输出量合同

对每个候选比较定义同一个 projection `P(C_matrix)`：到底是单对 coupling、两侧 coupling 之和、ground、total/self，还是 diagonal coupling。记录 conductor/net mapping、参考导体和所有接地电极。

统一 Maxwell 矩阵的符号、单位以及每单位长度/总电容含义。二维无限延伸模型返回的 F/m 不可直接与有限三维结构的 F 比较；需要明确长度与端部处理。固定长度乘法只能用于物理语义已匹配的分量。

原生 coupling-to-ground 阈值、合并同网导体、耦合折算、长度缩放和跨片段装配可能改变最终输出。在核函数级比较时优先追踪这些处理之前的对应值；若使用处理后的值，所有方法应用相同变换。

### 4.3 非网格和合法性判定

坐标比较首先在确定的数据库单位中进行；必须转换浮点时，容差由 DBU/文件精度预先确定。非网格不是“比浮点舍入误差大一点”。

合法性记录具体检查层级：来源布局的既有 DRC 状态、层合法性、最小宽度/间距、导体不相交、材料参数有效性和模式兼容性。只做几何规则检查时写“passes the implemented geometry checks”，不假称完成 foundry full DRC。

主研究对象是未修改实际布局产生的 off-grid queries。若为了压力测试生成几何扰动，必须放到单独的 synthetic perturbation 集，不进入真实布局普查分母，也不冒充已存在布局。

### 4.4 固定采样与拆分

在求解或查看方法误差前，根据几何、工艺、层和类别分层采样并固定 seed、样本 ID、采样概率及顺序。优先选择所有方法均能解释的物理交集；同时报告相对于全部查询的适用覆盖率。

开发/pilot 与正式评估按物理几何哈希划分；跨设计重复几何不可伪装成独立样本。已有八布局可用于新查询评测，但应说明是对既有布局的新查询级实验，不称未见设计测试。任何调参只使用独立开发/源验证数据。

## 5. 阶段 C：获取独立参考，分清插值误差与物理不一致

### 5.1 两条物理一致的实验路径

**路径 A：匹配物理的求值对照（优先用于解释插值误差）。**

在相同材料栈、边界条件、导体模式和分量定义下，为表征支持 S 和新查询 Q 分别提供参考。已有 S 记录只有在几何及求解配置哈希相同时才可复用。所有预测方法读取同一 S 的数值，Q 参考只由评估器保存。

原生控制应以可用 S 生成或装载兼容的规则，再运行原生求值代码。若目标分量无法写入其格式，不得随意构造假规则；将该控制降为准确标注的数值算法对照，记录 native scope 的缺口。

**路径 B：实际规则原样使用（部署相关性验证）。**

保留现有 process-specific 规则数据，追踪真实 native 求值，并用参考求解器评价可匹配的几何。先在 on-grid 上对齐量纲和物理定义。若原规则与参考求解已有系统差异，结果代表模型/校准/插值等综合误差，不能全部归因于插值。

不要把路径 A 重算后的表值称为晶圆厂原始值，也不要把路径 B 的规则—求解器差异静默“校准掉”。任何校准仅能用独立开发数据，且对所有方法一致；变更后单列实验。

### 5.2 参考求解的具体要求

优先复用已经安装且经过验证的 FEM/参考求解环境。可用的授权商业求解器或第二个独立实现可用于交叉检查，但不得假设许可证或工具可用，不得为了凑“独立”换成不支持相同介质/边界的求解器。

“independent reference”至少表示 Q 的标签通过直接物理求解获得，独立于本文预测和规则插值；使用同一 FEM 实现直接求解 S/Q 是合法的匹配物理实验。只有确实使用另一实现，才写 independent-solver cross-check。

先验证单位、导体编号、ground/total/coupling 投影、on-grid 对齐、网格及外域收敛。收敛规则在 pilot 上确定并冻结，可沿用本项目已有有效阈值；新增容差以支持集尺度和绝对数值分辨率定义。每个可计分样本必须有收敛证据或预定义复查状态，不能只验证一个容易案例。

原始参考至少保存：输入 geometry/material/boundary hash、求解器版本、网格等级、域大小、完整输出矩阵或电荷、projection、CPU 秒、墙钟、失败和收敛差值。reference uncertainty 与方法差距同量级时，不宣称可分辨优势。

### 5.3 防止混淆的数学口径

令 `g` 为实际几何，`P(g)` 为规则使用的简化模式，`I_S` 为规则求值，则同一电容分量有：

`I_S(P(g)) - C_ref(g) = [I_S(P(g)) - C_ref(P(g))] + [C_ref(P(g)) - C_ref(g)]`。

第一个括号才是相对于同一简化物理模型的求值误差；第二个括号是模式/几何近似差异。没有同时求解两种几何，就不能从总差中宣称识别了两个贡献。校准数据/材料不一致时，还需单列相应差异。

本轮首要目标是第一项及其工程出现范围。不要用一个复杂真实截面参考去比较未声明的对称模板预测，然后将结果全称“插值精度”。

## 6. 阶段 D：原生插值基线必须是真正的原生路径

### 6.1 比较方法的身份

至少报告以下适用方法：

| 标识 | 含义 |
|---|---|
| Native OpenRCX evaluator | 固定版本工具实际求值路径或从同一实现调用的测试 harness |
| Native-validated reimplementation | 独立复现并逐查询对原生输出核验的方法；不得省略 reimplementation 标签 |
| Rank-matched multilinear / local affine / GP | 明确的数值对照，不等同于所有商业工具 |
| Support anchor | 本文自己的数值参考，与 native 分开 |
| Ungated / Binary / Full | 已有模型，固定命名及权重 |
| Target-adapted MLP、已有 CNP | 同一支持标签预算的学习对照；维度和语义匹配时复用 |

AttentionCap 仅在导体和输出语义可对应的条件下沿用已有适配，不能为了加入表格而改变监督任务却不说明。Flash-CNNCap 不强行进入本次规则查询数值比较。

### 6.2 Native 验证

优先对原版与只读记录版跑同一小布局，核验其寄生输出不因日志而改变。测试节点、单元内部、边界、退化轴和工具特有 fallback；误差容差应基于输出格式及物理尺度，不使用一个远大于电容本身的绝对阈值。

必须保留函数/源文件/构建版本、调用参数、输入规则及返回值。若复制源码核函数作为独立 harness，明确它与实际提取路径的语义和配置等价性。原生输出不存在时，不能用“OpenRCX-style”自动补成“Native”。

如果当前 native 对某一类材料或分量不适用，不要阻塞其他可完成比较；给出明确覆盖和身份，论文的比较主张随实际可用控制调整。

### 6.3 数据公平性

所有方法使用同一 process/corner、S、Q、分量投影和单位。目标适配方法只能读取 S。源归一化、支持选择、门控选择和超参数均不得读取正式 Q 的参考电容。

核对 Full/Binary/MLP/CNP 的训练表与测试来源；已有 native 留出表及其重复内容必须从相应源训练/选择中排除。若模型必须适配新输入，仅在源/开发数据上做必要接口修复，不自动进行网络结构搜索。

保持 Full 和 Binary 是固定方法，不可按正式测试结果逐条件切换“Ours”。使用所有同样可用的表征点是本轮主协议；再次人为遮蔽属于单列的采样敏感性实验。

## 7. 阶段 E：当前模型能否处理任意 off-grid 查询，需要实际验证

### 7.1 实现显式 query API

在不改变现有模型语义的前提下，实现显式的：

`predict_queries(S_coordinates, S_values, Q_coordinates, context, checkpoint, query_policy)`。

推理输入只含 S 的值；不能要求 Q 必须属于原来的 128/153 节点网格。新 token 的归一化使用源训练尺度或已规定的 S-only 量，不因知道 Q 真值而变化。严格核验 `predict_table` 与新 API 在原有固定输入上的一致性。

已知 S 节点的恢复只作用于真正同节点查询。不能将最近节点值伪装为新的参考标签，不能以补零表示新增实际观测。

### 7.2 查询集合/批处理敏感性必须检查

当前模型支持 query–query attention，支持描述也可能依赖输入候选集合大小。因此“接受任意坐标”不意味着“单查询结果与拼批无关”。

在预先固定的开发查询上，检查同一 `(S,q)`：单查询、固定小批、固定大批、重排输入以及加入无标签其他查询时的输出变化。重排等变性和改变查询集合是两种不同检查。

固定主评估 batching 策略，例如按规则键聚合、按 geometry hash 排序后固定分块。统计与计时使用同一策略。若输出依赖批组成，论文写 batch-conditioned rule query evaluation；仍可以按这一协议完成真实查询评测，但不能把它当任意可缓存的点函数。未验证前不要把某批的 q 预测用于另一种调用方式的成本结论。

若需要改成仅 query-to-support attention 或改变支持特征，这属于方法变更和可能的重训，不得作为隐蔽的工程修复。本轮优先采用可复现的固定批协议。

### 7.3 成本记录

分开记录：layout 读取与查询提取、S 编码和数值分支、target fitting、forward、导出、native PEX/STA。多查询共享编码要报告实际共享方式，不能按样本数重复计费或把共享成本完全删除。

参考场求解在本实验中主要是生成评估标签，不等于部署时每次都要支付的成本。保留求解耗时，但不据此推导全芯片场求解替代加速。比较 CPU 秒与 CPU 秒、墙钟与墙钟，不直接相加不同口径。只有完整实现并计量的端到端流程才能声称端到端加速。

## 8. 阶段 F：分析哪些结果，才会加强论文主张

### 8.1 三个主问题

- **E1 / Relevance**：实际提取中有多少查询未命中表征节点？它们出现在哪些层、模式和几何区间？
- **E2 / Accuracy**：相同 S 下，本文方法对这些 Q 的直接参考误差是否低于 native 求值及强简单基线？
- **E3 / Usefulness**：精度改进、计算开销和适用覆盖是否构成实际可用的运行点？

先汇报全部同查询结果，再解释支持覆盖和方法复杂度；不以 Full 必须第一作为验收条件。

### 8.2 指标与统计

主表按相同 process/family/component 的实际查询集合计算 NRMSE 和绝对误差，同时给出 signed error、MAE、P95/P99、失败/不适用比例。对极小或零电容，保留绝对误差，不用随意 epsilon 制造优异相对误差。

分别报告：

1. unique-geometry 等权指标，解释几何泛化；
2. layout-occurrence 或 length-weighted 指标，解释在本布局中的使用频度；
3. per-design/per-process 分解，防止大设计掩盖其他结果。

若从唯一查询中分层抽样，使用记录的抽样概率及发生次数恢复布局权重，不能把平衡抽样直接当自然布局分布。误差比较必须配对到相同 Q；重复几何和共享规则组不是独立物理样本，统计 resampling 保留这些依赖。样本组很少时重点报告逐组值及范围，避免给出不适当的总体保证。

### 8.3 几何距离与机理分析

从 S-only 尺度定义查询到最近表征点距离、局部 cell 的相对位置、包围间距，以及支持域外距离。所有方法共用分箱，不能看误差后划分有利区间。

最有价值的图是“实际查询发生频度 + native/anchor/Full/Binary/MLP 的误差随覆盖距离变化”。这能回答本文是否确实修正了非采样位置的求值误差，比仅有一个平均误差表更能说明 EDA 作用。

数值锚点与 Full 的差异可显示修正收益；Full 与 Binary 的差异显示完整融合的增量。它们仍不单独识别每个数值分支或物理因素的因果作用，不要用门控权重图宣布学习到了电场或工艺机理。

### 8.4 系统验证的扩展条件

若原生规则格式支持增加节点，实施一次 offline rule enrichment：只添加模型预测，不写入正式 Q 的参考值；检查新节点确实改变了相关 native 查询，然后在固定 routed database 上运行提取/STA。检查不能仅以成功生成文件为准。

若不能直接扩充规则，完成可复现的 query-level replay 仍是有价值的交付。不要为了形成系统结果而将若干独立截面 C 直接拼成全芯片 SPEF；需要完整的聚合、归属、耦合及长度语义才可以这样做。

已有 full-rule PEX/STA 结果继续保留，作为规则导出保真度验证；本轮直接场求解 Q 是新的物理参考层。两者并列定义，不能把完整规则参考改名为独立物理真实值。
