# Frozen budget protocol

The executable JSON-compatible YAML is EXPERIMENT_PLAN.yaml. This is a new budget evaluation of already inspected cohorts, **not a new blind test**. Source fitting/validation and three published full members are exactly those in configs/paper_models.json and their FROZEN receipts. Control weights are loaded with SimpleControl; archived fixed-mask scores are never used as budget predictions.

Predictors receive only an explicit metadata allowlist, the entire fixed geometry grid, S and y_S. They never receive the original table dictionary with labels. Q is evaluator-owned and excluded from candidate queries; unqueried candidate labels are also sealed. Source target/coordinate scales remain frozen. All methods retain observed entries. Query batching is fixed to the full grid; no arbitrary online-query invariance is claimed.

Use geometry-only coverage for primary predictor comparisons; random/curvature share Q and initialization. One geometry returns all components and is charged once. Cache hits cost no extra query; original CPU characterization cost is charged once on first observation. Recorded fine-only and validated costs remain separate; no newly measured solver speedup. Source generation/training costs are historical when available and unknown otherwise, never zero by default.

Primary NRMSE pools squared error/truth by process/family/component before equal macro aggregation. Native component MAE and table P95/P99 retain physical units. No small labels are removed. Zero-truth component groups are excluded only from relative normalization and retained in absolute metrics. Failed predictions remain in coverage/failure tables and invalidate success comparisons; never silently drop a method's failed row. Budget coverage changes with table length, so curves at higher budgets describe their eligible subset. Short tables with 4--7 rows receive B=2; fewer than four rows cannot supply the prescribed context and sealed evaluation population and are excluded for every method with counts.

Independent GP is selected over the six existing length/ridge choices on source validation. Local affine reuses the published validation selections (4/8/8). CMI means explicitly implemented rank-matched multilinear with its documented sparse-corner/fallback behavior; it is not a measured proprietary tool. PCHIP is evaluated with repository sparse-grid fallback, and rank-2 fallback must be labeled. New MLP and CNP get two fixed learning rates, fixed endpoints, and source-validation selection only. MLP target fine-tuning uses the same S and no additional labels. The direct feature encoding includes material and thickness context but is a paper-inspired reimplementation, not Tsai's released implementation.

Thresholds are source-validation anchor error quantiles, not application-certified tolerances. Minimum **measured** budgets are reported with censored/not-attained tables retained. No interpolation between budgets. Group bootstrap does not turn two material stacks or repeated masks into independent processes. E3 budgets 4/8 and all eight saved layouts are fixed before results; only the original held-out 84 rule tables may be modified. Any budget infeasibility is explicit and shared. Native checks must cover exact untouched bytes, observed values, full-rule replay, net/endpoint identities, and fixed input hashes.

## Reporting clarifications (no scientific selection change)

FEM dependency groups span families within a process/layer. The bootstrap therefore samples whole dependency groups within process and keeps all their families intact, rather than fragmenting a physical group to impose family stratification. Training-seed sensitivity uses all three existing full/residual/binary members at data seed 11, with no model selection. Source-only baselines are displayed on common Q, but their effective target-query count is zero and they are excluded from equal-information efficiency comparisons. The pruning curve is labeled an ablation where validation does not select it. The resource job ceiling refers to top-level CPU batches; the separate prespecified native matrix comprises 240 candidate plus eight golden tool invocations.

The native budget covers only the selected eligible held-out tables. All other rule tables retain the original already-characterized values identically across methods. This does not measure rebuilding an entire PDK from scratch. Public fitting includes other tables of the same processes; only the FEM transfer protocol is source-process held out. The final manuscript and decision explicitly preserve this scope.

The newly trained MLP/CNP use 3000 updates, family-balanced uniform-table source sampling, and two learning rates. The original full/residual/binary controls use their archived longer schedules and original sampler. Thus only the latter constitute matched-training-budget architectural controls. New baselines match source data and target observations and receive bounded validation selection, but not identical update counts or process-balanced sampling. Claims of global optimality or universal superiority over direct learning are not licensed, especially on the imbalanced public corpus. The negative rank2 adapted-MLP result does not require weakening this baseline or expanding its search.
