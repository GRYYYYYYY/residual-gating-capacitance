# Related-work sources and implemented comparisons

- AttentionCap official source: https://github.com/THU-numbda/AttentionCap, pinned 59a48fd1f90e668c061fa27fb22b53ddad3db499; local supplied PDF read. The official symmetric-attention/Laplacian head is reused on reconstructible FEM conductor geometry. Our feature/boundary adapter and three-component projection are explicitly documented. It is not the original full-matrix benchmark. Same fitting/validation/Q/S, no extra matrix supervision, finite target fitting.
- Tsai et al., ICCAD 2025, https://www.gtcad.gatech.edu/www/papers/Tsai-ICCAD25.pdf; local Tsai-ICCAD25.pdf read. Author overview: https://mike84265.github.io/research/ml_pex.html. The work encodes layer thickness and predicts unseen thickness without per-thickness retraining; do not claim otherwise. Our direct MLP is a paper-inspired reimplementation using available geometry/material summaries, with source training and same-S target optimization. It does not reproduce the authors' layout slicing, feature matrices, data scale or netlist assembly.
- Flash-CNNCap, https://github.com/THU-numbda/flash-cnncap, official README and existing local pipeline reviewed. Three-dimensional window contribution images and capacitance matrix/netlist reconstruction differ from this fixed-rule-grid offline completion. No numerical comparison or faithful LUT-to-image reproduction is claimed. We do not claim full 3D extractor superiority.
- CNP and ANP establish conditioning on observation sets; ANP source https://arxiv.org/abs/1901.05761 checked. Our baseline is deterministic mean-aggregation CNP, not ANP. Context conditioning is not a first contribution.
- ResCap DOI 10.1145/3658617.3697737 and Accuracy-Based Hybrid PEX DOI 10.1109/TCAD.2022.3161199 are present in the original verified bibliography and discussed in the locally read Tsai paper. Fresh publisher access returned 403/unavailable. Do not imply fresh full-text verification. Residual and hybrid concepts are established prior work.
- AIL-DNN DOI 10.1109/TCAD.2025.3562947: publisher lookup unavailable in this environment. Treat detailed methodological claims as not independently reverified; retain conservative attribution for adaptive sampling/incremental learning and do not claim active-learning novelty. Our sampling controls use existing random/coverage/curvature functions; no new learned acquisition network is introduced.

Each baseline comparison reports our data, supervision projection and NRMSE. Numbers from unrelated papers using different error denominators are never ranked against this study.

Additional primary-source verification: the CNP paper page at https://proceedings.mlr.press/v80/garnelo18a.html and the Hybrid PEX author-institution abstract at https://fount.aucegypt.edu/faculty_journal_articles/4632/ were accessible. The latter supports the method-selection description but does not substitute for a newly verified full-text numerical benchmark.
