# Prespecified common FEM AttentionCap adaptation

Pinned official source 59a48fd1f90e668c061fa27fb22b53ddad3db499 is loaded without modifying the backbone or Laplacian matrix head. The adapter uses two 64-wide symmetric-attention layers, four heads and exponential positive edge weights. Inputs are recorded conductor rectangles, padded material-layer bottom/top/permittivity values, declared domain extent and an explicit external ground-boundary token. This changes the original feature interface and is labeled **adapted AttentionCap**, not a reproduction of the authors' reported benchmark.

The official matrix output is supervised only through the same three FEM components: sum of target-to-lateral edges, target-to-grounded plus boundary edges, and target-to-diagonal edges. Full FEM matrices are not used for learning; hence no extra label-component advantage. The source fitting and validation tables, target Q/S, seeds and budgets match E1. The same two learning rates and fixed 3000-update endpoint are used; target adaptation uses only paid S for 0/50/200 steps, chosen on source validation. The original homogeneous conductor feature interface cannot directly represent the heterogeneous FEM stack; explicit material padding and boundary projection make that discrepancy reviewable. Zero-observation results are information-limited controls, not the fair B-observation comparison.
