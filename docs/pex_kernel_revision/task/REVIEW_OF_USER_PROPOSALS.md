## 当前能够积极强调的目标

“在生产相关规则求值内核上改善未表征几何的电容估计；通过计算表预生成，把学习开销与运行时高频查表分离。”

这是研究目标与部署设计。精度提高的条件、实现范围和耗时由同支持、同查询实验给出。

## 最重要的比较层级

1. **生产相关算法主比较**：OpenRCX求值核、xRC-derived MLI/标准MLI、本文。
2. **方法必要性/组件分析**：Anchor、强数值候选、numeric-only、Binary、Full。
3. **任务适配比较**：adapted AttentionCap、MLP、CNP，明确输入/输出/训练机会。
4. **实际部署**：原生不修改、原生数值pass-through、学习值computeTable注入；固定节点规则导出作为已实现路径另列。

## 数据集与参考的关系

原生返回值可用作实现一致性参照，不可同时作证明“超越原生物理精度”的真值。为了公平比较两类生产求值公式，可以把同一组FEM表征值输入两个内核，并以独立FEM查询解为参考。这证明的是“该内核在匹配物理数据上的算法表现”，不是完整Calibre或原生PDK的提取质量。
