# DAC PEX 插值内核修改任务包

本包是对用户六点修改建议的技术审核及Codex执行指令，不是已完成的新实验，也不直接改动GitHub。

先将整个目录交给Codex，再粘贴 `START_CODEX.txt`。

- `CODEX_DAC_PEX_KERNEL_REVISION.md`：完整执行任务书。
- `REVIEW_OF_USER_PROPOSALS.md`：逐项采纳/修正原因。
- `PAPER_TEXT_SNIPPETS.md`：正式论文写法与统计量定义。
- `SOURCES_AND_SCOPE.md`：精确提交、官方来源和证据范围。
- `START_CODEX.txt`：启动指令。
- `SHA256SUMS`：交付文件哈希。

主要目标：两类生产插值内核主对照、必要组件对照、全部留出率、前置真实需求图、内部计算表回填及完整流程成本。保留所有已完成正面和反面结果，避免将方法级对比误标为商业工具实测。
